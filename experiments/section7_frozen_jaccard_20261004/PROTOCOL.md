## 验收与停止

模型无关 fixture 检查独立副本、丢弃写入、复杂 canary 不进入候选、修改过的 checkpoint 被拒绝、48 题检索与原 top-3 完全一致，并验证沙箱无主机目录、网络或 API key。运行后逐题检查冻结库、候选/注入哈希及每次真实 payload 中的记忆映射。

第一题有基础设施异常或未知 usage 时不扩大。后续出现基础设施、记忆/评分异常或未知 usage 时停止派发，已在运行的任务保留完成记录；审查原因后才决定剩余范围，不自动重跑已执行目标。普通答案错误保留原分数，不视为接线失败。

以逐题及整体的 total/input/output/cache tokens、工作工具和 SUBMIT、重复调用/错误观察代理、延迟、正确性为主；代理不直接称浪费。新执行费用与历史源库成本分别报告。旧 No Memory/Jaccard 为历史参考，来源与写入策略、执行时间同时改变，本次 R=1 不隔离各因素、不证明稳定提升。

skill_manage gotchas: (1) a patch op on a supporting file (e.g. references/question-patterns.md) needs the file_path field — omitting it targets SKILL.md and the old_string won't match; (2) old_string must be copied verbatim from read_file of the actual file — skill_view's rendered output can paraphrase/normalize details (numbers, wording) and will fail fuzzy match; (3) after repeated identical patch failures, read the file tail with read_file first instead of retrying the same string.

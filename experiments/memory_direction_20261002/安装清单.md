## Hermes 及配套运行时

Hermes 源码固定到 `07ab19b0a399f33bd760852e0b0588d07efe8c22`，下载于 `.runtime/hermes-source`。官方 PowerShell 安装器在仓库阶段 TLS 失败；随后 Git 单次使用 OpenSSL 后端下载，调用官方 `python -m pm.cli install --without agent-browser --without cua-driver` 成功安装核心运行依赖。阶段 03 进一步完成了实际 Agent 实验。

Hermes 的独立工具目录为 `.runtime/hermes-tools`，包括 Python 3.14.7+20260901、uv 0.12.3、Node 26.7.0、npm 12.0.2、FFmpeg 9.0.1、ripgrep 15.2.0。FFmpeg/Node 等由官方 PM 默认依赖闭包安装。补装 `--extra anthropic` 后，当前 Python 环境含 117 个发行包，完整版本逐项见 `hermes-python-packages.json`；所有保留的应用环境代际及 PM 环境见 `hermes-all-environments.json`，路径和校验信息见 `installation-manifest.json`。已实际跑通 SQL、原生记忆、原生历史搜索。

HERMES_HOME、运行时目录、LOCALAPPDATA、UV_CACHE_DIR 仅对安装及实验进程重定向到实验目录。原生文件工具额外设置进程级 `HERMES_GIT_BASH_PATH=D:\Git\bin\bash.exe`，复用已有 Git Bash，没有另装 Git。没有发布系统命令、修改全局 PATH、安装浏览器/CUA、Docker 或 WSL。下载缓存和逐次 profile 位于被 Git 忽略的 `.cache`、`.runtime` 中。

保留的环境包括当前应用环境 117 个发行包、旧应用环境 115 个发行包、PM 独立环境 4 个发行包。逐项包名和版本均在 `hermes-all-environments.json`；包数不是互不重复的软件数量。当前可选 Anthropic SDK 为 0.87.0。

新增公开数据下载：LongMemEval oracle、MemoryAgentBench Conflict Resolution、小量 BFCL 数据及源码片段。它们是数据／源码缓存，不是新安装的完整 Agent。读取 parquet 和切分 token 使用主机原有 Anaconda 环境中的 pyarrow 22.0.0、pandas 2.2.2、tiktoken 0.12.0，未为此安装新包。

## 保留一个方向的最低证据

1. 记录具体输入、环境版本、Agent/模型和完整可复算结果。
2. 问题至少在独立重复或另一个任务族复现，标出样本范围与不确定性。
3. 对照完整 Agent、简单现成方案；不能靠弱化模型、错误提示、剥掉真实范围来制造差距。
4. 用纠正信息或受控消融说明存在实际改善空间；不必实现新优化系统。
5. 同时记录新增开销、恢复能力和否定结果。

## 已排除或降级的解释

- debug-v0 的 GLM 15.52%：缺少原始共同背景，属于实验接入错误，不是 memory bad case。
- 将设置文件的 autoMemoryEnabled=true 当成原生记忆已经生效：实际输入未包含索引，因此不成立。
- c 的单次耗时上升等同于稳定负迁移：目前证据不足。
- 根据错误单位 SQL 的结果，声称 Agent 已答错：反事实只能作机制诊断。
- 把当前记忆问题的价格和时间两个例子分别算两个方向：属于同类范围泛化，不能重复计数。
- Q9 首次出现无记忆正确、记忆错误，不等于稳定因果效应：第二次正好反向，必须保留重复结果。
- 正常入口生成的两份价格记忆正确限定 g2，不能继续把 restricted 的跨表泛化当作正常入口必然缺陷。
- MAB 第二块 8k 输出上限下续写失败属于预算干扰；已用 32k 重跑，保留两组证据。
- MAB q3 触及本地请求保护不等于已证明记忆逻辑错误，不能混入普通答案准确率。
- 原子检索初次诊断同时改变了展示时间戳，因此不是纯块大小消融。
- 后续已补保留父时间戳的原子检索，并跑通原生文件回退；当前证据不依赖首次混杂对照。

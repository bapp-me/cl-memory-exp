## 最终检查

- 309 个运行目录均有 summary 和 finished 状态；无未结束模型进程需要等待。
- 1520 次实际请求核验模型、thinking、effort/原生 reasoning_effort 和 32768 输出上限；响应模型名为 deepseek-flash、glm-5.3-flash。
- 3040 个 HTTP request/response 原始体无损压缩，解压长度/SHA256 逐个匹配。
- 无 max_tokens/length 截断响应。2 个 Agent 错误是已列出的上游网络失败与角色配置失败；另 1 个完成但数值错误保留在质量表。
- 所有来源快照相等性、存储与索引版本一致性通过。GLM 原生请求实际保留历史 reasoning_content 的记录可见，不只写配置文件。
- 已对交付文件及 gzip 解压内容扫描两把实际凭据，没有发现泄漏。扫描报告只返回文件/计数，不输出密钥。
- 7 项本地单元检查通过：评分私有性/SQL 只读、错误覆盖与重复 join、状态不匹配拒绝、版本与副本隔离、CSV/时窗、报告规格精度、PATCH 拒绝后状态不变。Python 编译与 Node 语法检查通过。
- `git diff --cached --check` 在最终提交前执行。原始模型/HTTP 记录不做去空格等内容改写；结果目录不按源码空白规范修改，代码仍做检查。

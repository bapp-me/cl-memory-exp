# 来源与导出边界

三个实验目录保留原工作区文件字节及相对路径。导出源提交和每个文件的哈希见 `export-manifest.json`；后加的仓库入口和 `tools/` 不冒充实验时源码。

本轮原始轨迹归档在独立归档中，包括研究者侧评分日志；不应把整个证据目录作为 agent 的可读工作区。源任务、hidden tests 和评分器的隔离边界见原协议与实验过程。

上游来源及固定版本分别见本轮 `records/source-assets.json`、`records/agentcl-selection.json`、`records/database-assets.json`、`records/noncode-protocol.json`，早期轮次的 installation/environment 清单，以及 `pi-package-lock.json`。主要来源包括 AgentCL、CL-Bench、AgentBoard、BigCodeBench、Pi 和 Hermes。

未打包第三方依赖安装目录或整个下载数据缓存。保留的 fixtures、任务文本、模型轨迹及引用材料用于本私有研究仓库的复核；其上游许可仍适用。本次整理未替第三方材料授予新的许可，也未将仓库改为公开。
